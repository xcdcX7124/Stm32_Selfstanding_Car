硬件部分采用了网上视频博主的方案，使用转接板的方式连接所有模块并通过亚克力和铜柱搭建小车框架。
软件部分则为我本人从0开始搭建，使用KEIL5标准库开发。

OLED模块部分使用了江协科技开源的OLED模块库，通过软件模拟I2C，定义PB8为SCL引脚，PB9为SDA引脚与OLED模块通讯。

通过TIM1的PWM输出模式在PA8和PA11输出PWM信号到TB6612电机驱动模块控制电机，同时通过PB12 PB13 PB14 PB15
来输出电平到TB6612控制电机的旋转方向。

编码器通过TIM2和TIM4的方式来获取编码器数据，并在处理后发送到PID程序里进行计算。

通过软件模拟I2C的方式定义PB3为SDA引脚，PB4为SCL引脚，与MPU6050通信获取姿态数据，并将得到的原始数据使用互补滤波的方式进行处理
后交给PID程序计算。

配置USART3，与JDY-08通过串口进行通信，接收来自ESP32遥控器发送的遥控数据。


特色功能：

自起立控制：通过状态机实现从侧倒状态自启动并保持自稳

防飞车保护：倾角超限（>35°）切断动力

失联看门狗：遥控小车运动时超时（50ms）未接收到操作信息则自动停在原地防止失控

抗积分饱和：状态切换/复位时清空 PID 缓存

开机自校准：每次启动计算陀螺仪零偏并去除

三环串级 PID：直立 PD + 速度 PI + 转向 PD
